# Тодо Бичик

Интерактивный атлас и самоучитель ойратского алфавита **Тодо Бичик**. Интерфейс на русском, работает как PWA (можно установить и пользоваться офлайн).

Репозиторий: [github.com/lovsans/TODO](https://github.com/lovsans/TODO)

## Возможности

- Справочник букв и форм
- Курс «Путь», тренажёры, прописи
- Озвучка букв и слогов (кнопка ▶ на карточке)
- Поиск, тема, сохранение прогресса
- Экспорт PDF

## Запуск

Статический сайт — сборка не нужна. Запускайте из корня проекта:

```powershell
npx --yes serve .
```

или `python -m http.server 8080`

Не открывайте `index.html` через `file://` — для PWA нужен локальный сервер.

## Озвучка

Подключены буквы, **элементы**, **цифры**, **пунктуация**, **слова**, **краткие выражения**, **загадки**, **составить слово** и **все 145 слогов**:

```
audio/vowels/…  consonants/…  galik/…  elements/…  numbers/…  punctuation/…
audio/words/…  audio/compose/…  audio/reading/expr/…  audio/reading/riddles/…  audio/syllables/…
```

Файлы `.m4a` не входят в первый офлайн-кэш оболочки: скачиваются при нажатии ▶ и после этого доступны офлайн.

## Структура

- `index.html` — главное приложение
- `writer.html` — тренажёр штрихов
- `audio/` — озвучка букв
- `css/`, `js/`, `img/`, `fonts/` — стили, логика, медиа
- `manifest.webmanifest`, `sw.js` — PWA

`writer-edit.html` и `_gh-check/` — служебные файлы, не часть обычного UI.
