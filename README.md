# Тодо Бичик

Интерактивный атлас и самоучитель ойратского алфавита **Тодо Бичик**. Интерфейс на русском, работает как PWA (можно установить и пользоваться офлайн).

Репозиторий: [github.com/lovsans/TODO](https://github.com/lovsans/TODO)

## Возможности

- Справочник букв и форм
- Курс «Путь», тренажёры, прописи
- Озвучка букв и слогов (кнопка ▶ на карточке)
- Поиск, тема, сохранение прогресса
- Экспорт PDF

## Запуск

Статический сайт — сборка не нужна. Запускайте из корня проекта:

```powershell
npx --yes serve .
```

или `python -m http.server 8080`

Не открывайте `index.html` через `file://` — для PWA нужен локальный сервер.

## Публикация на Reg.ru

Сайт статический, сборка не нужна. В панели хостинга откройте **Файловый менеджер** и загрузите содержимое этой папки в `www` (иногда называется `public_html`). В корне `www` должен лежать `index.html`.

Не загружайте папки `.git` и `_gh-check`.

1. Привяжите домен к хостингу.
2. Выпустите бесплатный SSL (Let’s Encrypt) в разделе сертификатов — без HTTPS не заработает офлайн-приложение.
3. Откройте сайт по домену: должна показаться главная «Тодо Бичик».

Файл `.htaccess` включает HTTPS, перенаправляет `www` на основной домен, задаёт типы `.webmanifest` / `.m4a` / `.woff2`, страницу 404 и закрывает служебные редакторы. `robots.txt` и `sitemap.xml` содержат основной домен `https://todobichig.ru`.

## Автообновление с GitHub на todobichig.ru

GitHub сам сайт на Reg.ru не пушит: репозиторий и хостинг — разные места. Связка такая: вы пушите в `main` → GitHub Actions по FTP заливает файлы в `www`.

1. В панели хостинга Reg.ru возьмите FTP: сервер (часто `todobichig.ru` или IP `31.31.196.187`), логин и пароль. Домашняя папка FTP-пользователя должна быть корнем сайта (`www`), где лежит `index.html`.
2. На GitHub: репозиторий **Settings → Secrets and variables → Actions → New repository secret**. Добавьте три секрета:
   - `FTP_SERVER` — хост FTP без `ftp://`
   - `FTP_USERNAME`
   - `FTP_PASSWORD`
3. Залейте в репозиторий файл `.github/workflows/deploy-regru.yml` (он уже в этом проекте) и сделайте push в `main`.
4. Вкладка **Actions**: зелёная галочка — файлы ушли на [todobichig.ru](https://todobichig.ru). Дальше каждый push в `main` обновляет сайт сам. Кнопка **Run workflow** — выгрузка вручную.

Пароли в репозиторий не кладите. Если FTPS не пускает, в workflow замените `protocol: ftps` на `ftp`.

Другой путь, без Actions: SSH на хостинг, в корне сайта один раз `git clone https://github.com/lovsans/TODO.git .`, потом после обновлений `git pull`. Это не автомат: pull нужно делать самим или повесить на cron.

## Запуск SEO после публикации

На сайте есть отдельные индексируемые материалы: история письма, алфавит, правила письма и чтения, самоучитель, тексты, сингармонизм и галики. Все адреса перечислены в `sitemap.xml`.

### Яндекс Вебмастер

1. Добавьте сайт `https://todobichig.ru` в [Яндекс Вебмастер](https://webmaster.yandex.ru/).
2. Подтвердите права удобным способом. Если Яндекс выдаст HTML-файл, положите его в корень рядом с `index.html` и опубликуйте.
3. Откройте **Индексирование → Файлы Sitemap** и добавьте `https://todobichig.ru/sitemap.xml`.
4. Отправьте главную и новые тематические страницы на переобход.
5. После появления данных проверяйте запросы, исключённые страницы, дубли и ошибки обхода не реже раза в месяц.

### Google Search Console

1. Добавьте ресурс-домен `todobichig.ru` в [Google Search Console](https://search.google.com/search-console/).
2. Подтвердите его TXT-записью в DNS Reg.ru.
3. В разделе **Sitemaps** отправьте `https://todobichig.ru/sitemap.xml`.
4. Через **Проверку URL** запросите индексирование главной и ключевых материалов.

Search Console и Вебмастер не ставят рекламные cookie. Яндекс Метрика и Google Analytics намеренно не подключены: для них нужно отдельное решение по аналитике и обновление информации о приватности.

### Ежемесячный контроль

- какие запросы уже дают показы и переходы;
- какие страницы находятся в индексе;
- нет ли ошибок 404/500 и проблем с sitemap;
- совпадают ли canonical, внутренние ссылки и адреса в sitemap;
- какие реальные поисковые формулировки стоит добавить в существующий текст без переспама.

## Озвучка

Подключены буквы, **элементы**, **цифры**, **пунктуация**, **слова**, **краткие выражения**, **загадки**, **составить слово** и **все 145 слогов**:

```
audio/vowels/…  consonants/…  galik/…  elements/…  numbers/…  punctuation/…
audio/words/…  audio/compose/…  audio/reading/expr/…  audio/reading/riddles/…  audio/syllables/…
```

Файлы `.m4a` не входят в первый офлайн-кэш оболочки: скачиваются при нажатии ▶ и после этого доступны офлайн.

## Структура

- `index.html` — главное приложение
- `writer.html` — тренажёр штрихов
- `audio/` — озвучка букв
- `css/`, `js/`, `img/`, `fonts/` — стили, логика, медиа
- `manifest.webmanifest`, `sw.js` — PWA

`writer-edit.html` и `writer-strokes-edit.html` — служебные редакторы, в обычном UI не открываются.
